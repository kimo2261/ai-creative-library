## النشر على GitHub Pages
1. أنشئ مستودعًا عامًا باسم `ai-creative-library`.
2. ارفع الملفات الأربعة `index.html`, `data.js`, `app.js`, `README.md` إلى جذر المستودع.
3. افتح Settings > Pages واختر Deploy from a branch ثم `main` و`/(root)` واضغط Save.
4. انتظر ظهور رابط الموقع داخل إعدادات Pages. يكون عادة `https://USERNAME.github.io/ai-creative-library/`.

لا يحتاج الموقع إلى مفاتيح API أو قاعدة بيانات. المفضلة محفوظة في localStorage على كل جهاز بشكل منفصل. GitHub Pages عام وليس مناسبًا لحماية المحتوى السري.
